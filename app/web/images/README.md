# Image provenance

Every `.jpg` in this folder is **AI-generated** (via an external image generator, at the user's
request) to stand in for real project/site photography on the N.S. Construct demo site. None of
these depict real N.S. Construct buildings, real client sites, or real completed work.

They exist so the `/site` renderer has something better than a blank box while real photography
isn't available yet. Before this site is used for anything beyond an internal demo, every image
here should be replaced with actual photos of real projects (or clearly licensed stock), and the
corresponding `image` field in the relevant page's widget config (via the widget editor or the
Website Studio API) updated to point at the replacement.
